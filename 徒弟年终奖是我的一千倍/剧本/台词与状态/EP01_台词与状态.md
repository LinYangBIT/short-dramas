### 锁定规则

1. **音色只锁一次**：Voice Design（无参考）生成每角色参考音频，之后所有台词走 Voice Direction（参考音频 + 台词指令）。
2. **同一角色永不复用别人的 ref**；跨集、跨单元不变。情绪、语速只通过 `instruction` 调整。
3. **每条台词的 seed 固定**（2001 起），重出时结果稳定，便于 A/B。
4. 参考音频的 `ref_text` 必须逐字等于实际朗读内容，已写入 `voices.json`。
5. Breeze 支持行内表演事件：中文用方括号（`[笑]`、`[叹气]`、`[清嗓子]`），只在确有表演时加。

## 三、与画面的对齐

- **U06/U07 台词密集**：L04–L08 按自然语速会比单元略长。合成指令已要求“语速快”，成片仍紧时按 1.05–1.15× atempo 微调。
- **两处 J-cut**：01-13 的尾句跨过 U06→U07 切点；01-16 的尾句延续到 U08 李恒背影，形成“背后被议论”的压迫感。
- **01-10 “理由”**：前后各留 0.3–0.5″ 空白，让音乐骤停成立。
- **01-20 画外**：不要加气声，不要煽情，音量低于环境声。

## 四、合成流程

```bash
# 1. 启动本地服务（H3 视频批次结束后再起，避免显存冲突）
BREEZE_MODEL_PATH=/modelset/model/base/Breeze-TTS-2 bash /workspace/breeze-tts/run_server.sh

# 2. 先锁 13 个角色音色（每角色一条参考音频，落 refs/）
/home/yunzhongshan.yl/envs/breeze-tts/bin/python run_tts.py --refs

# 3. 试听 refs/，确认音色后合成 EP01 全部台词（落 lines/）
/home/yunzhongshan.yl/envs/breeze-tts/bin/python run_tts.py --lines

# 可选：A/B 某个角色 / 重出某句
/home/yunzhongshan.yl/envs/breeze-tts/bin/python run_tts.py --refs --only C03
/home/yunzhongshan.yl/envs/breeze-tts/bin/python run_tts.py --lines --only 01-12 --force
```

输出：24 kHz 单声道 WAV + 同名 JSON（文本、指令、seed、参考音频、实测时长）。
