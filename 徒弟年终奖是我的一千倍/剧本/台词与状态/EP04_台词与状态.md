### 锁定规则

1. **音色只锁一次**：Voice Design（无参考）生成每角色参考音频，之后所有台词走 Voice Direction（参考音频 + 台词指令）。
2. **同一角色永不复用别人的 ref**；跨集、跨单元不变。情绪、语速只通过 `instruction` 调整。
3. **每条台词的 seed 固定**（EP02 起 2101，逐集 +100），重出时结果稳定，便于 A/B。
4. 参考音频的 `ref_text` 必须逐字等于实际朗读内容，已写入 `voices.json`。
5. Breeze 支持行内表演事件：中文用方括号（`[笑]`、`[叹气]`、`[清嗓子]`），只在确有表演时加。

## 四、合成流程

```bash
# 1. 启动本地服务
BREEZE_MODEL_PATH=/modelset/model/base/Breeze-TTS-2 bash /workspace/breeze-tts/run_server.sh

# 2. 合成 EP04 全部台词（落 lines/）
/home/yunzhongshan.yl/envs/breeze-tts/bin/python run_tts.py --lines --episode EP04

# 可选：重出某句
/home/yunzhongshan.yl/envs/breeze-tts/bin/python run_tts.py --lines --episode EP04 --only 04-N1 --force
```

输出：24 kHz 单声道 WAV + 同名 JSON（文本、指令、seed、参考音频、实测时长）。
