## 四、已知偏差与处理

| 问题 | 影响 | 处理 |
|---|---|---|
| 李恒视觉年龄偏 38–40 | 与设定 35 岁略有偏差 | 可接受；七年老员工，疲惫感优先 |
| 高敏偏精致、模特感 | 与"38岁刻薄主管"略有偏差 | 可接受；靠表演与台词压住 |
| 支票、信封、表彰栏无文字 | 无法直接使用 | 后期贴图或动态合成 |
| 陈凯支票尺寸偏大 | 不影响叙事 | 后期缩放或换道具合成 |
| U01 高敏 2–4.5 秒换脸 | 女主开场脸漂移 | 只用 0–1.8″（冷脸走近）与 4.6–6.0″（李恒抬眼、高敏肩部入画），中段弃用 |
| U02 手部皮肤偏老、末段手指发软 | 与 35 岁李恒不符 | 取前 3 秒 + 0.75 倍慢放为 4 秒；不做近裁（上采样会软化） |
| U04 支票票面有乱码数字 | 特写可见 | 用 `¥3,000,000` 贴图覆盖 |
| U08 纸箱 1.6 秒后消失、7.5 秒后出现台面空箱 | 抱箱离职的连续性断裂 | 只用 0–1.6″ 抱箱背影；01-19 回望改用 KF04 静帧缓推，弃用 1.6″ 之后全部画面 |
| U06 单镜头拍完三段台词 | 拆三条会跳切，整集时长需重排 | 一镜到底，前后两段 0.85× 慢放 + 中插李恒近景；口型对齐版成片 59.48″ |
| 同事私语光线略偏暖 | 与冷灰蓝主调有偏差 | 调色时压色温 |
| 多人同框时后景人物脸略糊 | 竖屏浅景深正常 | 不需要修复 |
